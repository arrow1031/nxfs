## 上盘后的识别流程（下一窗口照做）

1. **重新采集**：Get-Disk | Sort-Object Number | Select-Object Number,FriendlyName,SerialNumber,@{n='SizeGB';e={[math]::Round(\.Size/1GB,2)}},NumberOfPartitions,IsBoot,IsSystem
2. **做差**：与上表比对 ⇒ 找出**新增盘号**；若新增盘号 ∈ {0,1,2,3,4,5,6} 的既有盘 ⇒ **立即停止**（说明识别失败，不得写入）。
3. **当面确认**：把新增盘的 Model + Serial + SizeGB + Parts 报给操作者确认"就是这块老机械盘"。
4. **盘无关三道闸**（`dev/onsite-98` 起；实现见 `nxfs-impl/tools/nxfs_physdisk.{h,c}` + `tools/d0_mkfs.c`，决策记录见 `tools/README.md` **D6**）：
   ① **只允许显式 `--disk N`**（没有自动挑盘；未声明 / 越界 ⇒ 退出码 **3**）；
   ② **`--expect-serial <SN>` 硬闸**：工具打印该盘 **Model / Serial / SizeGB / Parts / IsBoot / IsSystem** 的**实际值**，与 `<SN>` 不一致 / 读不到 / 没给 ⇒ 退出码 **4**；
   ③ **`IsBoot==true` 或 `IsSystem==true` 一律拒**（读不到也拒），且写扇区 0 打魔数 `NXFS-DISK0-PROBE` 并**读回逐字节比对**，不 MATCH 即中止。
   另**保留**：毒盘黑名单（`SAMSUNG`/`TOSHIBA`/`faspeed`，按 Model 不依赖盘号）、分区数**双来源取更严者**、核身/写入**两次打开**；容量只留 **64 MiB 合理性下限**（**不再有 119.24 GiB 窗口**——那是旧目标 INTEL SSD 的身份）。
   零写子命令：`--disk N --identify-only`（只读打印身份，**一个字节都不写**）；`--probe-only` **会写 1 个扇区**（打魔数），两者别混。
5. **回滚**：失败时把该盘恢复为"0 分区"（Clear-Disk -Number N -RemoveData 需**再次确认盘号与序列号**），绝不留下半成品而不自知。

## 4. 上盘后第一步（下一窗口照做，不要跳步）

1. `Get-Disk | Sort-Object Number | Select-Object Number,FriendlyName,SerialNumber,@{n='SizeGB';e={[math]::Round($_.Size/1GB,2)}},NumberOfPartitions,IsBoot,IsSystem`
2. 与《上盘前盘位基线》**做差** ⇒ 得**新增盘号 N**。
   - 若结果落在基线**已有**盘号上 ⇒ **停止**（识别失败，不得写入）。
   - 若 `IsBoot -or IsSystem` ⇒ **绝对停止**。
3. 把 `N / Model / Serial / SizeGB / Parts` 报给操作者**当面确认**（"这就是那块 15 年老机械盘"）。
4. 确认后：`--disk N --expect-serial <SN>`（工具须回显身份并核对；不一致即中止）。
5. 写入前**魔数闸**：扇区 0 打 `StFS-DISK0-PROBE` → 读回比对 → MATCH 才继续。
6. 顺序：**先只读探测**（看盘上现状）→ 再格式化（MBR + 分区 + StFS）→ 再只读挂载 + 判据校验 → 最后记录证据（型号/序列号/容量/耗时/结果）。
7. 失败回滚：`Clear-Disk -Number N -RemoveData`（**再次**确认盘号与序列号），并在报告里写清失败时的盘上状态。

# NXFS

模块化机械盘专用文件系统——面向 3.5" 机械硬盘，CoW 事务 + 三层日志 + 跨文件区 + 文件夹块自包含。
核心追求：写入不卡顿、长期不碎片化、断电可恢复、程序运行近原生延迟、绝不蓝屏。

> 当前版本：设计稿 v0.6.1 ｜ **一期（机械盘侧）进行中** ｜ 二期（NAND）已冻结
